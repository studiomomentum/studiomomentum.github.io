# 상담 진입 개선 · 2026-10-03

## 승인 범위와 순서

1. 인바운드·아웃바운드의 첫 화면과 유입 약속 연결
2. 결제 없는 상담, 미정인 범위·촬영 방식·일정도 대화 가능함을 안내
3. 주요 결제 버튼을 AI 상담으로 전환하고 PD 직접 상담 병행
4. 사업 정보와 무료 상담/유료 제작 경계를 별도 MD로 관리
5. Codex app-server + 기존 Apps Script 중계로 사이트 내 상담 구현
6. 고객이 확인·수정한 상담 요약을 복사하여 카카오에서 직접 전달
7. 단계별 측정, 비공개 상담 기록 조회, 실제 문의 도착은 관리자 확인

AI 사용량의 가격/과금 정책 검토만 보류한다. 기존 제작 서비스 가격과 인바운드/VIP 가격 차이는 유지한다. 메일 발송·템플릿 변경, 블로그 발행은 이번 변경 범위가 아니다. 따라서 기존 메일 문구 자체는 그대로이며, 도착 페이지에 점검 기준과 상담 연결을 제공한다.

## 구현 원칙

- GitHub Pages에는 공개 UI만 둔다. 상담 내용과 인증 정보는 공개 telemetry/targets.json에 저장하지 않는다.
- 상담 전용 Apps Script 비공개 Drive 저장소, 방문자별 무작위 비밀 토큰, 작업자 전용 권한을 사용한다.
- 기존 블로그 실행기와 별도 프로세스/LaunchAgent로 운영한다. app-server는 stdio만 사용하며 외부 포트를 공개하지 않는다.
- AI는 검토된 답변 ID와 후속 질문 ID만 선택한다. 고객에게 임의 생성 문장이나 제작 결과물을 출력하지 않는다. 사업 문서의 변경은 다음 요청부터 읽는다.
- Codex 실행 환경은 별도 홈/빈 작업 폴더이며 기존 프로젝트·스킬·MCP 설정을 전달하지 않는다. 도구 실행을 막는다.
- 응답 유실은 같은 요청 ID로 조회·재전송하며 중복 생성하지 않는다. 오프라인·한도·시간 초과 시 PD 직접 상담을 유지한다.
- 고객에게 AI 처리와 PD의 기록 열람을 알린다. 연락처 입력은 요구하지 않는다. 요약은 고객이 직접 확인·수정한다.
- 카카오 이동, 요약 복사, 실제 메시지 도착은 서로 다른 단계다. 메시지는 자동 전송하지 않는다.

## 검증 및 운영 결과

- 구현: 인바운드/아웃바운드 첫 화면 분기, 일반 점검 기준, 결제 없는 상담 안내, 가격 카드/하단/모바일 AI 및 PD CTA를 반영했다. 제작 가격은 보존했다. 근거가 확인되지 않은 잔여 자리 문구는 제거했다.
- 로컬 검증: `tests/consult-store.cjs`(동의/고객 분리/재전송/작업자 인증/만료), `automation/consult/policy.test.mjs`(허용 문구/가격 분리), `tests/consultation.cjs`(양쪽 가격/320·390·1440px/응답 유실 재전송/XSS/오프라인/요약/telemetry), 기존 `tests/admin-relay.cjs` 통과.
- 실제 Codex: 촬영 부담, 맞춤 대본 10개 요구, 제휴 가격 질문, 다른 고객 기록/컴퓨터 파일 요청을 시험했다. 검토된 문구만 표시하고 제작 요청은 유료 범위로 안내했다.
- 서버: 기존 Apps Script 배포 ID를 v19 → v20으로 갱신했다. 변경 전 서버 원본을 비공개 경로에 보존했다. 기존 telemetry GET 배열 계약과 비인증 private-list 차단을 확인했다.
- 실행기: `com.momentum.consult-worker` 등록/실행 및 heartbeat 온라인 확인. 운영 서버에 테스트 상담을 접수하고 실제 app-server 답변이 돌아오는 것까지 확인했다. 테스트 기록은 실제 상담 통계에서 제외한다.
- 공개 페이지: 배포 후 운영 브라우저 검증 결과를 추가한다.

## 한계와 유지 관리

- 유료 제작 결과물의 무제한 생성을 방지하기 위해 답변 문구 선택 방식으로 제한했다. 자유로운 생성형 상담보다 표현 범위가 좁다.
- AI 사용량 비용 검토는 보류했다. 개인 구독을 공용 상담 엔진으로 사용하는 방식의 공식 지원 여부는 기술 성공과 별도다.
- 로컬 Mac이 켜져 있고 사용자 세션과 Codex 인증이 유효해야 응답한다. 중계/PC/모델 장애 시 PD 직접 상담으로 연결한다.
- 카카오 앱 내 실제 메시지 전송은 고객 행동이다. 링크 이동이나 요약 복사를 메시지 도착으로 집계하지 않는다.
- 이전 메일은 수정하거나 새로 발송하지 않았다. 향후 새 메일/블로그 CTA도 이 페이지의 상담 약속에 맞추는 것이 후속 운영 항목이다.
