# 로그인 유지 — 2026-10-16

관리자페이지에서 로그인 상태 유지를 선택하면 고정 만료 기간 없이 로그인 상태를 유지한다. 로그아웃하면 서버 인증을 폐기한다. 로그인 상태 유지를 선택하지 않으면 기존 8시간 만료를 적용한다. 유효한 기존 저장 로그인은 재접속 때 만료 없는 인증으로 전환한다. 이미 만료된 인증은 되살리지 않는다.

자동글쓰기 실행기는 관리자 세션 대신 작업 전용 인증을 사용한다. 작업 조회·결과 회신만 허용하며 관리자 설정 변경·새 글 생성 요청·공개 발행 요청은 허용하지 않는다. 실행기 인증을 재등록하면 이전 인증은 폐기한다. 관리자 로그아웃과 실행기 인증은 독립적이다.

쿠키·사이트 데이터 삭제, 다른 브라우저·기기에서는 처음 로그인이 필요하다. 네이버·티스토리·쓰레드·AI 서비스 자체의 로그인 정책은 이 변경 범위에 포함하지 않는다.

검증: 기억된 관리자 로그인에 20년 경과를 적용한 테스트, 로그아웃 폐기, 기존 저장 로그인 전환, 임시 로그인 만료, 실행기 인증 권한 제한과 재등록 폐기 테스트. 운영 검증 기록은 작업 문서에 유지한다.
