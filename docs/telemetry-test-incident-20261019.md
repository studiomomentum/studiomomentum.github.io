# 2026-10-19 브라우저 검증 기록의 운영 통계 혼입

수원 병원 페이지를 11초간 표시하고, 백그라운드 전환 후 2초간 다시 표시하는 자동 검증을 반복했다. 따라서 반복되는 13초는 실제 고객 체류가 아닌 검증 시나리오의 값이다.

일반 fetch는 Playwright에서 가로챘지만 페이지 종료 때의 sendBeacon을 별도로 차단하지 않았다. 테스트 종료·이동 시 전송된 이탈 이벤트와 대기 중이던 상호작용 일부가 운영 저장소에 도달했다. 확인한 9개 세션, 61개 이벤트를 테스트로 식별했다. 원본은 감사 근거로 보존하고 해당 세션 ID만 일반 집계·CSV에서 제외한다. 다른 방문을 수원 페이지·체류시간·헤드리스 여부만으로 제외하지 않는다.

브라우저 테스트의 공통 초기화에서 운영 ntfy 및 Google Script fetch 목적지를 예약된 `.invalid` 도메인으로 변경하고 sendBeacon을 비활성화한다. Playwright 라우트가 종료된 뒤에도 운영 서버로 전송할 수 없도록 두 경로를 분리 차단한다. 회귀 테스트에서 실제 URL 변환, 비콘 미실행, 확인된 테스트 세션 제외와 무관한 방문 보존을 검증한다.
