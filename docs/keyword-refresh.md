# 출처별 TOP 10 수동 갱신

2026-09-30 사용자 최종 요청: 네이버 검색·데이터랩·vidIQ를 각각 수동 갱신한다. 주간 자동 갱신과 카운트다운은 취소했다. 7일이 지나도 요청·크레딧 사용을 자동 실행하지 않는다.

## 화면과 저장

- 콘텐츠 관리의 각 출처 카드에 `갱신하기` 버튼과 `마지막 갱신 후 N일 N시간 N분 경과`를 표시한다. 페이지 재접속 시에도 서버에 저장된 각 출처의 관측 시각으로 계산한다.
- 세 버튼 모두 확인 팝업을 표시한다. vidIQ는 최대 20크레딧 안내를 추가한다. 취소하면 요청하지 않는다.
- 경과 시간은 성공한 출처의 새 자료가 저장될 때만 초기화된다. 실패·대기·실행 중에는 기존 자료와 시각을 유지한다. vidIQ는 7일 경과 안내만 표시한다.
- 같은 출처의 중복 요청은 기존 대기/실행 작업으로 합친다. 다른 출처는 별도로 대기열에 등록되며 PC 실행기가 순서대로 처리한다. 글·발행 작업과 구분한다.
- 인증된 비공개 Drive 저장소를 사용한다. PC가 꺼지면 요청은 대기한다. PC 실행기 관리자 세션 만료 시 재로그인이 필요하다.

## 수집 범위

- 네이버 검색: 등록된 10개 키워드를 헤드리스 Chrome에서 재검색하고 검색 글 표본을 갱신한다. 검색량 순위가 아니다.
- 데이터랩: 등록된 10개 키워드의 3개월 일별 추이를 재조회하고 최근/직전 28일 상대 관심도 변화율로 정렬한다. 절대 검색량이 아니다.
- vidIQ: 공식 MCP OAuth 연결. 기획·촬영·편집 외주·마케팅 4개 씨앗을 조회하고 `keyword-framing.mjs`에 정의한 사업 관련어 중 30일 이내 지표의 기회 점수 상위 10개를 고른다. 전체 유튜브 키워드 순위가 아니다. 조회 전 무료 잔액 확인을 수행하며 20크레딧 미만이면 유료 조회를 시작하지 않는다.
- vidIQ 조회 중 PC 실행기가 중단되면 자동 재조회하지 않는다. 이미 차감됐을 가능성을 표시하고 기존 자료를 보존한다. 응답 수신에 실패한 유료 호출도 자동 재시도하지 않는다.
- OAuth 토큰은 `~/Library/Application Support/MomentumBlog/vidiq-mcp-auth.json`에 0600으로 저장한다. 코드·공개 사이트에 포함하지 않는다. 설정 시에만 보이는 Chrome을 사용하며 MCP 조회는 브라우저 없이 실행한다.
- 재연결: `node automation/blog/vidiq-mcp.mjs`. 공식 승인 창에서 사용할 계정을 확인한다.

## 검증

- 서버: 출처별 중복 차단, 서로 다른 출처 대기열, 다른 출처 결과 제출 거부, 성공한 출처만 변경, 실패 시 기존 관측 시각 보존, 대기 작업 없을 때 자동 생성 없음.
- 화면: 3×10개 목록, 개별 버튼, 확인 취소/승인, 경과 일·시간·분 계산, 1440/390/320px 가로 넘침 없음.
- 실제 PC MCP 연결로 무료 잔액 조회 성공. 150크레딧 확인. 기존 대화 플러그인의 잔액과는 다르므로 같은 계정이라고 단정하지 않는다.
- vidIQ 4회 유료 갱신은 이 변경 검증을 위해 별도 소비하지 않았다. 이전 조회 자료로 10개 선별 로직을 검증했다.

## 운영 반영 확인

- Apps Script 동일 배포 ID를 v15로 갱신했다. 배포 직전 원본은 `/private/tmp/momentum-deploy-20260929/backup-before-source-refresh-20260930`에 보존했다.
- 웹 구현 커밋 `f3a8aa9`, Pages 실행 `36588029583` 성공. 운영 `admin.html`에서 개별 버튼 3개, 경과 시간 3개, 목록 30개 확인. vidIQ 확인 팝업의 20크레딧 안내와 취소 동작 확인. 1440/390/320px 가로 넘침 및 페이지 오류 없음.
- 운영 PC 실행기로 네이버 검색·데이터랩을 각각 요청해 두 작업 모두 `complete` 확인. 두 출처만 갱신됐고 vidIQ 자료·관측 시각, 기존 글 전체, 발행 이력이 그대로인 것을 변경 전후 비교했다.
- 실행기 관련 모듈만 백업·교체하고 서비스를 재시작했다. 다른 작업의 생성기 변경은 덮어쓰지 않았다. 주간 스케줄·자동 갱신은 배포하지 않았다.
