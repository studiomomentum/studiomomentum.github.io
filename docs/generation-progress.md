# 글 생성 진행 표시 (2026-09-29)

- 기존 생성 작업을 확인한 결과, 새 주제 유튜브 기획의 세 매체 초안 v1은 서버에 완료 저장돼 있었지만 화면이 요청 직후 대기에 머물렀다.
- 사용자 요청에 따라 생성 중 전체 콘텐츠 재렌더링을 제거하고 단계 진행 막대를 표시한다: queued 0%, running 50%, complete 100%. 생성기의 토큰별 진행률이 아닌 서버 작업 단계 기준임을 화면에 명시한다.
- 3초마다 백그라운드 상태를 조회하며 생성 중에는 진행 표시만 갱신한다. complete를 확인하면 100% 표시 후 0.5초 뒤 결과 영역을 갱신한다. failed는 완료로 표시하지 않는다. 연결 실패는 재확인 상태로 남긴다.
- 미저장 편집이 있으면 결과로 덮어쓰지 않고 안내한다. 전송 작업의 기존 별도 상태 갱신은 유지한다.
- 검증: 실제 Chrome UI에서 생성 중 편집 영역 DOM 보존, 서버 완료 후 자동 결과 표시/100%, 320px 가로 넘침 없음, 생성 중 사용자 편집 보존, 기존 저장/검수/발행 버튼 회귀 통과.
- 상태 전이 검증은 fixture이며 새 실제 생성·발행은 요청하지 않았다. 서버의 기존 완료 글은 읽기로 확인했다.
- 운영 배포 확인 중.
