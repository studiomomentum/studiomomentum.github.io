## 연동

- 기존 콘텐츠 카드의 임시저장/검수/공개 발행/결과 복구 흐름에 네이버 추가. 검수 전 공개 발행은 서버에서 거부.
- `automation/blog/naver-delivery.mjs`는 내 블로그 주소를 검사하고 SmartEditor에서 줄 단위로 입력한다. 한 번에 본문 입력 시 줄바꿈이 사라지는 문제를 피한다.
- 같은 제목의 임시저장본은 제목·본문 줄을 대조한다. 중복 제목이나 내용 충돌은 덮어쓰지 않고 중단한다. 임시저장 목록을 모두 확인할 수 없는 경우에도 중단한다.
- 최초 편집기 로딩의 임시저장 개수 0은 최종 결과가 아니다. 실제 목록 응답 완료 후 목록 개수와 항목을 대조한다.
- 최종 클릭 전 기존 delivery receipt를 저장한다. 불명확한 결과는 재클릭하지 않고 실제 글 확인/운영자 복구를 사용한다. 결과 URL은 `blog.naver.com/jungkkuckma/숫자`만 허용한다.
- 공개 발행 경로는 구현했으나 이번 작업에서 공개 게시하지 않았다. 실제 첫 발행의 완료 여부와 본문은 별도 확인해야 한다.
