# 매일 홍보글 자동 작성·발행

사용자 승인: 2026-10-17. 한국시간 매일 10:00·18:00에 주제 하나씩 네이버·티스토리·쓰레드에 공개 게시한다. 하루 주제 2개, 게시물 6개다. 최우선 목표는 조회수 증가이며 사업은 전문직 전담촬영이다. 주제는 외주 구매 질문으로 한정하지 않고 사업에 도움이 되는 분야로 넓힌다.

## 실행 흐름

기존 momentum-blog.service의 직렬 루프에서 autopilotOnce를 호출한다. 별도 작업자가 브라우저 프로필을 동시에 점유하지 않는다. 설정은 비공개 실행 폴더 autopilot-config.json, 계획·버전·발행 이력 연결은 autopilot-state.json, 조회수 관측은 autopilot-metrics.json에 저장한다. 서버 주제·원고·검수·발행 대기열은 기존 콘텐츠 관리 화면을 그대로 사용한다. 예약 제어는 기존 비공개 관리자 세션으로 필요한 콘텐츠 API만 호출하고, 실제 생성·전송 작업자는 기존 전용 토큰을 사용한다. 인증 파일을 공개 저장소에 넣지 않는다.

게시 30분 전부터 하루 주제 2개를 기획하고 해당 시각의 원고를 생성·자동 검수한다. G17 원문의 세대 일치를 확인한다. 예약 쓰레드에도 G17의 중심 질문·도입·연결·판단 원칙을 적용하되 반말·500자 이내·URL 제외를 유지한다. 블로그는 기존 매체별 지침을 적용한다. 생성은 로컬 Antigravity CLI다. 쓰레드가 길면 한 번만 사실·의미를 유지해 축약하고 다시 500자 검증을 한다.

자동 검수는 규칙 검사와 AI 검수다. 사람이 읽은 것을 의미하지 않는다. 승인된 정확한 버전만 서버 검수 완료 후 정시에 공개 발행 요청한다. 원고가 수정되면 지문 불일치로 보류하며 편집본을 덮어쓰지 않는다. 발행은 매체별 순차 실행이므로 10시·18시는 요청 기준이고 실제 게시에는 처리 시간이 더 필요하다.

## 조회수 반영

약 3시간마다 최근 완료 게시물의 조회수를 읽는다. 네이버는 로그인한 소유자의 게시물별 통계 화면이 불러온 누적 cvTotal, 티스토리는 글별 통계의 base 응답 count와 permalink, 쓰레드는 소유자 인사이트의 게시물 ID별 Views를 사용한다. 실패·로그인 필요·화면에 없는 게시물은 unavailable 및 null로 남긴다. 0은 플랫폼 응답이 확인된 경우에만 기록한다. 쓰레드 인사이트에 보이는 최근 목록보다 오래된 글은 미확인이 될 수 있다. 수집만으로 새 로그인·유료 키워드 조회를 실행하지 않는다.

비교 대상은 자동 게시글의 게시 후 20~28시간 중 24시간에 가장 가까운 관측값 하나다. 매체를 섞지 않고 글 형식과 주제 분야별로 비교한다. 같은 형식·분야에 3건 이상 있어야 중앙값을 기획에 제공한다. 충분한 표본이 있으면 좋은 형식·분야를 우선 참고하면서 일부 다른 적합한 구성을 시험하도록 기획한다. 주제·배포·시간 등의 영향이 있어 조회수 차이를 형식의 인과 효과로 단정하지 않는다. 기존 글의 현재 누적 조회수를 동일 연령 성과로 꾸미지 않는다.

## 복구와 제한

날짜·시간별 계획과 게시할 버전을 요청 전에 저장한다. 응답이 유실되면 기존 주제·생성 작업·같은 버전의 발행 요청을 조회해 중복 생성을 피한다. 불확실한 게시 결과는 기존 전송 receipt로 복구하며 자동 재클릭하지 않는다. 로그인·검수·콘텐츠 충돌·게시 실패는 보류 또는 실패로 남긴다. 예정 시각보다 2시간 이상 늦어진 미요청 슬롯은 몰아서 발행하지 않으며, 이미 대기열에 들어간 예약 게시도 최종 클릭 전 만료를 검사한다. 최종 클릭 후에는 만료로 미게시 판정하지 않고 결과만 복구한다.

PC가 켜져 있고 서비스·로그인·AI 사용 가능 상태여야 실행된다. 시스템 서비스는 부팅 시 자동 시작한다. 조회수 증가나 매일 6건 성공을 보장하지 않는다. 상태는 바탕화면 매일_홍보글_자동화_상태.txt와 서비스 로그에서 확인한다. 예약 설정 enabled=false는 새 예약 처리를 중지하며 이미 서버에 접수한 요청을 자동 취소하지는 않는다.

## 검증 명령

운영 실행 폴더의 automation/blog에서 MOMENTUM_BLOG_HOME 및 MOMENTUM_PD_SKILL_DIR를 서비스와 같은 값으로 지정한다.

- node autopilot-cli.mjs status: 현재 설정·계획·성과 비교 확인
- node autopilot-cli.mjs metrics: 기존 발행글 조회수 수집. 공개 글 작성·발행 없음
- node autopilot-cli.mjs preview: 주제 2개와 첫 주제의 세 매체 원고·자동 검수를 로컬에서 시험. 서버 글 저장·발행 없음
- node --test tests/autopilot.test.mjs tests/generator.test.mjs: 시각·재시작·중복 요청·검수·조회수 비교 검증
