# 블로그 글쓰기 형식 지침

2026-09-30 사용자 합의에 따라 `automation/blog/generator.mjs`의 네이버·티스토리 공통 프롬프트에 반영했다.

검색 의도는 독자가 원하는 답·판단이며 글쓰기 형식은 그 답을 전달하는 전개 방식이다. 둘을 별도로 판단하고 각 글의 주 형식 하나와 필요한 보조 형식을 선택한다.

| 주 형식 | 중심 역할 |
|---|---|
| 설명형 | 개념·원리·이유 이해 |
| 방법·절차형 | 목표 달성을 위한 실행 순서 |
| 비교형 | 같은 기준에 따른 선택지의 차이 |
| 사례 분석형 | 구체적 상황과 판단 과정 |
| 문제 진단형 | 증상에서 원인을 좁히는 방법 |
| 체크리스트형 | 준비 사항과 조건 점검 |
| 질문·답변형 | 중심 고민에 연결된 여러 질문 해소 |
| 오해 교정형 | 통념을 근거와 조건으로 바로잡기 |
| 선택 가이드형 | 독자의 상황에 따른 결정 |
| 전후 개선형 | 구체적인 변경 지점과 이유 |
| 자료·트렌드 해석형 | 데이터·변화의 의미와 한계 |
| 관점·주장형 | 입장·근거·반론·성립 조건 |

- 네이버·티스토리 각각의 중심 질문과 근거에 맞춰 선택한다. 같은 형식이어도 되며 형식을 순환·무작위·균등 배정하지 않는다.
- 보조 형식은 중심 질문의 이해를 돕는 범위에서 결합한다.
- 실제 사례·성과·통계를 꾸미지 않는다. 가상 사례와 가상 전후 예시는 가상임을 명시한다. 자료·트렌드 해석형은 관련 자료와 기준 시점·범위가 있을 때만 선택한다.
- 형식명·선택 이유·기획 메모는 공개 글에 출력하지 않는다.
- 이번 범위는 프롬프트 추가다. 형식 선택 UI·저장 필드는 추가하지 않았다. 쓰레드 지침은 변경하지 않았다.

검증: Node 문법 검사 및 기존 생성기 테스트 3건 통과. 쓰레드 지침과 생성 실행 함수의 변경 전후 동일성 확인. 실제 새 글의 형식 선택·품질은 이번 작업에서 생성하지 않아 미검증이다.

운영 적용: 대기·실행 중인 생성/발행/키워드 작업이 없음을 확인한 뒤 PC 실행기의 기존 generator.mjs를 백업하고 이 파일만 교체했다. LaunchAgent 재시작 성공 및 소스/실행기 SHA-256 일치 확인(`9007ece996dbf8126b54404d2b4801236c3dda8ba2c533af271ba541fb58afc9`). 다음 생성부터 적용되며 기존 글은 변경하지 않았다. 웹·Apps Script 배포는 필요하지 않다.
