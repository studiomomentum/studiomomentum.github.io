# 매체별 새 버전 생성 (2026-09-30)

- 각 카드에 네이버만 / 티스토리만 / 쓰레드만 새 버전 생성 버튼 추가. 기존 전체 새 버전 생성 유지.
- 요청의 platform을 서버 작업 platforms로 고정하고 실행기·AI JSON 스키마·출력 검증·완료 저장까지 전달한다. 기존 작업은 세 매체로 해석해 호환한다.
- 선택 매체만 버전 추가 및 검수 해제. 다른 매체의 원문·버전·검수·발행 이력은 보존. 기존 게시물을 수정하거나 다시 발행하지 않는다.
- 미저장 편집이 있으면 저장 후 요청하도록 안내. 주제 내 생성은 기존 직렬 처리 유지. 재시도도 선택 매체를 유지하며 생성 도중 해당 원문이 편집되면 충돌로 보존한다.
- 진행 막대에 선택 매체를 표시하며 서버 완료 시 결과를 불러온다.
- 검증: 세 매체 각각의 단독 생성/다른 매체 보존/잘못된 출력·매체 거부/재시도 범위/편집 충돌 테스트, 생성기 3건, 실제 Chrome 카드 버튼·진행률·모바일·원문 보존 회귀 통과.
- 운영 Apps Script 기존 4개 파일을 백업하고 ContentStore만 변경해 동일 URL 버전 14 배포. 실제 content.get의 platforms·잘못된 매체 거부·기존 글 불변 확인 완료.
- 운영 실행기는 generator와 worker의 매체 전달 부분만 갱신해 재시작. 다른 작업의 키워드 자동화 변경은 그대로 보존.
- 실제 AI 단독 생성 및 발행 요청은 이번 기능 검증에서 하지 않았다. 새로 생성할 매체는 사용자가 카드에서 선택한다.
